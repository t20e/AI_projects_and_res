# Loss Vs Cost Functions

**Loss function**: Measures the error (or loss) for a single training sample/example, i.e., a data point. If I have a dataset of dog images, a single image and its label is one sample.

**Cost function**: Measures the overall error (or cost) across the entire training dataset. It's typically the average of the loss functions over all training examples per one epoch. This is the function that optimization algorithms like batch gradient descent aims to minimize.

They are often used **interchangeably**.
